## About

I’m **Aditya Sharma**, a **3rd-year Computer Science student** focused on building **inspectable AI systems** and **reliable backend services**.

I’m drawn to problems where **data**, **retrieval**, and **systems design** meet:
- **AI systems:** embeddings, semantic retrieval, document intelligence, evaluation-minded iteration  
- **Backend engineering:** API design, data modeling, performance, reliability, clean boundaries  
- **Applied ML:** prototypes that stay honest about constraints (data, metrics, deployment reality)

## How I build

- **Inspectable > magical:** I prefer systems with metrics, traces, and clear failure modes.
- **Prototype fast, refactor deliberately:** early feedback first, then tighten architecture.
- **Measure iteration:** baselines + evaluation harnesses over guesswork.
- **Maintainability beats demos:** boring reliability is a feature.
